# AI Status Menubar 다운로드

ChatGPT, Claude, Gemini, NotebookLM, Grok 같은 AI 서비스가 잘 돌아가는지를 **macOS는 메뉴바**, **Windows는 시스템 트레이(작업 표시줄 오른쪽)** 에서 한눈에 확인할 수 있는 작은 앱입니다.

색깔로 알려줍니다:
- 🟢 **초록** = 다 잘 됨
- 🟡 **노랑** = 조금 느려짐
- 🟠 **주황** = 일부 문제
- 🔴 **빨강** = 큰 장애
- ⚪ **회색** = 점검 중이거나 확인 불가

## ⚠️ 아직 시험판(알파)입니다

이 앱은 **만든 지 얼마 안 된 시험 버전**이에요. 그래서:

- 가끔 색이 회색으로 잠깐 바뀔 수 있어요 (각 AI 회사 홈페이지가 바뀌면 일시적으로 못 읽을 때가 있습니다)
- 디자인이나 기능이 자주 바뀔 수 있어요
- **자동 업데이트가 없습니다** — 새 버전은 이 페이지에서 다시 받으셔야 해요
- 처음 실행할 때 OS가 한 번 경고합니다 (정상이에요, 아래 설치 방법 참고)

문제가 생기면 [👇 아래 문의 방법](#문제가-생겼을-때) 을 봐주세요. 알려주시면 큰 도움이 됩니다!

# 🍎 macOS 설치

## 내 맥에서 쓸 수 있나요?

| 항목 | 필요한 사양 |
|---|---|
| 맥 종류 | **M1, M2, M3, M4 칩이 들어간 맥** (Apple Silicon) |
| 운영체제 | **macOS 13 이상** (Ventura / Sonoma / Sequoia) |

> **내 맥 확인하는 법**: 화면 왼쪽 위 🍎 → "이 Mac에 관하여" 클릭. "칩"이 **Apple M1/M2/M3/M4**로 시작하면 OK입니다.

## 1단계: 다운로드

👉 [**AIStatusMenubar.dmg 받기**](./AIStatusMenubar.dmg) (545 KB, 매우 가볍습니다)

## 2단계: 설치

1. 다운로드 폴더에서 **`AIStatusMenubar.dmg`** 더블클릭
2. 작은 창이 뜨면, 안에 있는 **`AIStatusMenubar`** 아이콘을 **`Applications` 폴더**로 끌어다 놓으세요
3. 끝났으면 그 창은 닫아도 됩니다

## 3단계: 처음 실행하기 (중요!)

이 앱은 일반 앱스토어 앱이 아니어서, **처음 실행할 때 맥이 한 번 막습니다.** 무서워하지 마시고 아래 순서대로 해주세요.

### 🆕 macOS 15 (Sequoia) 사용자

1. `응용 프로그램` 폴더에서 **AIStatusMenubar** 더블클릭
2. **"확인되지 않은 개발자"** 같은 경고가 뜨면 → **취소** 또는 **완료** 클릭
3. 🍎 → **시스템 설정** 클릭
4. 왼쪽 메뉴에서 **개인정보 보호 및 보안** 클릭
5. 오른쪽 화면을 **아래로 쭉 스크롤**
6. "**'AIStatusMenubar'이(가) 차단되었습니다**" 같은 문구가 보일 거예요 → 옆의 **"확인 없이 열기"** 버튼 클릭
7. 비밀번호 또는 Touch ID 한 번 확인
8. 다시 한 번 **"열기"** 클릭

### 📺 macOS 13–14 (Ventura / Sonoma) 사용자

1. `응용 프로그램` 폴더에서 **AIStatusMenubar** 아이콘 위에서 **마우스 우클릭** (또는 Control + 클릭)
2. 메뉴에서 **"열기"** 클릭
3. 경고 창이 뜨면 다시 **"열기"** 클릭

> 💡 한 번만 이렇게 열면 다음부터는 그냥 더블클릭으로 열려요.

## 4단계: 알림 받기 (선택)

1. 화면 오른쪽 위 **메뉴바에 생긴 작은 아이콘** 클릭
2. 팝업에서 **"환경설정..."** 클릭
3. **"상태 변경 시 알림"** 토글을 켜세요
4. 맥이 알림 권한을 물으면 **"허용"**

## 5단계: 맥 켤 때 자동으로 실행하기 (선택)

1. 메뉴바 아이콘 클릭 → **환경설정**
2. **"로그인 시 자동 시작"** 토글 켜기

# 🪟 Windows 설치

## 내 PC에서 쓸 수 있나요?

| 항목 | 필요한 사양 |
|---|---|
| 운영체제 | **Windows 10 (1809+) 또는 Windows 11** (64비트) |
| 추가 설치 | 없음 — .NET 런타임도 같이 들어있어요 |

## 1단계: 다운로드

👉 [**AiStatusMenubar-0.1.0-win-x64.msi 받기**](./AiStatusMenubar-0.1.0-win-x64.msi) (62 MB)

## 2단계: 설치

1. 다운로드 폴더에서 **`AiStatusMenubar-0.1.0-win-x64.msi`** 더블클릭
2. **"Windows에서 PC를 보호했습니다"** 같은 SmartScreen 경고가 뜨면:
   - **"추가 정보"** 클릭
   - **"실행"** 버튼 클릭
3. 설치는 자동으로 진행됩니다 (몇 초). **관리자 권한 불필요** — 내 계정 폴더에만 설치돼요
4. 끝나면 시작 메뉴에 **"AI Status Menubar"** 가 생깁니다

> 💡 SmartScreen은 새로운 앱이라 코드 서명이 없어서 뜨는 거예요. 같은 이유로 macOS도 처음에 경고가 떠요.

## 3단계: 실행

- 시작 메뉴에서 **AI Status Menubar** 검색 → 클릭
- 또는 설치된 폴더: `%LOCALAPPDATA%\Programs\AiStatusMenubar\AiStatusMenubar.exe`

실행하면 작업 표시줄 오른쪽 **시스템 트레이의 `^` overflow 메뉴** 안에 **녹색 체크 원 아이콘**이 생깁니다.

### 트레이 아이콘을 항상 보이게 고정하기

Windows 11은 새 앱의 트레이 아이콘을 처음에 overflow에 숨깁니다. 항상 보이게 하려면:

1. 작업 표시줄 오른쪽의 **`^` 화살표**를 클릭해서 overflow 열기
2. 녹색 체크 원 아이콘을 **드래그**해서 시계/볼륨 옆 빈 공간으로 옮기기

## 4단계: 사용법

- **좌클릭** 또는 **더블클릭** → popover에서 5개 서비스 상태 확인
- **우클릭** → 메뉴 (열기 / 새로고침 / 환경설정 / 종료)
- popover 헤더의 **📌 핀** → 외부 클릭에도 닫히지 않게 고정
- popover 헤더를 **드래그** → 화면 위치 이동
- popover 우하단 모서리를 **드래그** → 크기 조절
- 환경설정의 **"상세 모드"** → 서비스별 모든 하위 컴포넌트 펼쳐 보기

## 5단계: 로그인 시 자동 시작 (선택)

환경설정 → **"로그인 시 자동 시작"** 체크박스 켜기. HKCU\Run 레지스트리에 자동 등록됩니다.

## 삭제하고 싶을 때

설정 → 앱 → 설치된 앱 → "AI Status Menubar" 검색 → 제거.
또는 PowerShell에서:
```powershell
Get-Package "AI Status Menubar" | Uninstall-Package
```

## 사용법 (공통)

설치하고 나면 화면에 작은 색깔 아이콘이 생깁니다(macOS는 메뉴바 오른쪽, Windows는 시스템 트레이). 이게 5개 AI 서비스 상태를 종합한 결과예요.

- **아이콘 클릭** → 서비스별 상세 상태 펼쳐 보기

- **환경설정**에서 표시할 서비스, 알림, 확인 주기(15-600초), 상세 모드 등을 조정할 수 있어요

## 자주 묻는 질문

**Q. 이 앱이 내 데이터를 가져가나요?**
A. 아니요. 각 AI 회사의 **공개 상태 페이지**(누구나 볼 수 있는 페이지)만 주기적으로 확인합니다. 로그인이나 API 키 같은 건 일절 쓰지 않아요.

**Q. 인터넷 사용량이 많이 늘어나나요?**
A. 거의 없어요. 1분에 한 번씩 작은 데이터(몇 KB)만 받습니다. 변경 없으면 ETag로 304(빈 응답)로 처리해서 더 줄어요.

**Q. (macOS) "손상되었습니다"라고 뜨면서 안 열려요.**
A. 드물게 그런 경우가 있어요. 터미널(`응용 프로그램 → 유틸리티 → 터미널`)을 열고 아래 명령을 복사해서 붙여넣고 엔터:
```
xattr -dr com.apple.quarantine /Applications/AIStatusMenubar.app
```

**Q. (Windows) SmartScreen이 막아요.**
A. "추가 정보 → 실행" 순서로 진행하면 됩니다. 코드 서명이 없는 새 앱이라서 그래요.

**Q. (Windows) 트레이에 아이콘이 안 보여요.**
A. Windows 11은 새 앱 아이콘을 작업 표시줄의 `^` overflow 안에 숨깁니다. `^`를 클릭해서 펼친 다음, 녹색 체크 원 아이콘을 빈 트레이 영역으로 드래그하면 고정돼요.

**Q. 메뉴바/트레이 아이콘이 회색이에요.**
A. 인터넷 연결을 확인해보시고, 아이콘 → 새로고침 버튼을 눌러보세요. 회사 네트워크나 방화벽 때문일 수도 있어요.

**Q. (Windows) 자동 시작이 안 돼요.**
A. 환경설정의 "로그인 시 자동 시작" 체크가 켜져 있는지 확인하세요. 또는 `Win + R` → `shell:startup` 또는 `regedit`에서 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 에 `AiStatusMenubar` 항목이 있는지 확인.

**Q. 삭제하고 싶어요.**
A. macOS: `응용 프로그램` 폴더에서 AIStatusMenubar를 휴지통으로. Windows: 설정 → 앱 → AI Status Menubar → 제거.
