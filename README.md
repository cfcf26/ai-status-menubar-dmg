# AI Status Menubar 다운로드

ChatGPT, Claude, Gemini, NotebookLM, Grok 같은 AI 서비스가 잘 돌아가는지를 **맥 화면 위쪽 메뉴바에서 한눈에** 확인할 수 있는 작은 앱입니다.

색깔로 알려줍니다:
- 🟢 **초록** = 다 잘 됨
- 🟡 **노랑** = 조금 느려짐
- 🟠 **주황** = 일부 문제
- 🔴 **빨강** = 큰 장애
- ⚪ **회색** = 점검 중이거나 확인 불가

---

## ⚠️ 아직 시험판(알파)입니다

이 앱은 **만든 지 얼마 안 된 시험 버전**이에요. 그래서:

- 가끔 색이 회색으로 잠깐 바뀔 수 있어요 (각 AI 회사 홈페이지가 바뀌면 일시적으로 못 읽을 때가 있습니다)
- 디자인이나 기능이 자주 바뀔 수 있어요
- **자동 업데이트가 없습니다** — 새 버전은 이 페이지에서 다시 받으셔야 해요
- 처음 실행할 때 맥이 한 번 막습니다 (정상이에요, 아래 설치 방법 참고)

문제가 생기면 [👇 아래 문의 방법](#문제가-생겼을-때) 을 봐주세요. 알려주시면 큰 도움이 됩니다!

## 내 맥에서 쓸 수 있나요?

| 항목 | 필요한 사양 |
|---|---|
| 맥 종류 | **M1, M2, M3, M4 칩이 들어간 맥** (Apple Silicon) |
| 운영체제 | **macOS 13 이상** (Ventura / Sonoma / Sequoia) |

> Intel 칩이 들어간 옛날 맥은 아쉽지만 안 됩니다.
>
> **내 맥 확인하는 법**: 화면 왼쪽 위 🍎 → "이 Mac에 관하여" 클릭. "칩"이 **Apple M1/M2/M3/M4**로 시작하면 OK입니다.

## 1단계: 다운로드

👉 [**AIStatusMenubar.dmg 받기**](./AIStatusMenubar.dmg) (500 KB, 매우 가볍습니다)

위 파란 글씨를 클릭하면 파일이 다운로드 폴더에 받아집니다.

---

## 2단계: 설치

1. 다운로드 폴더에서 **`AIStatusMenubar.dmg`** 더블클릭
2. 작은 창이 뜨면, 안에 있는 **`AIStatusMenubar`** 아이콘을 **`Applications` 폴더**로 끌어다 놓으세요
3. 끝났으면 그 창은 닫아도 됩니다

---

## 3단계: 처음 실행하기 (중요!)

이 앱은 일반 앱스토어 앱이 아니어서, **처음 실행할 때 맥이 한 번 막습니다.** 무서워하지 마시고 아래 순서대로 해주세요.

### 🆕 macOS 15 (Sequoia) 사용자

1. `응용 프로그램` 폴더에서 **AIStatusMenubar** 더블클릭
2. **"확인되지 않은 개발자"** 같은 경고가 뜨면 → **취소** 또는 **완료** 클릭
3. 🍎 → **시스템 설정** 클릭
4. 왼쪽 메뉴에서 **개인정보 보호 및 보안** 클릭
5. 오른쪽 화면을 **아래로 쭉 스크롤**
6. "**'AIStatusMenubar'이(가) 차단되었습니다**" 같은 문구가 보일 거예요 → 옆의 **"확인 없이 열기"** 버튼 클릭
7. 비밀번호 또는 Touch ID 한 번 확인
8. 다시 한 번 **"열기"** 클릭

### 📺 macOS 13–14 (Ventura / Sonoma) 사용자

1. `응용 프로그램` 폴더에서 **AIStatusMenubar** 아이콘 위에서 **마우스 우클릭** (또는 Control + 클릭)
2. 메뉴에서 **"열기"** 클릭
3. 경고 창이 뜨면 다시 **"열기"** 클릭

> 💡 한 번만 이렇게 열면 다음부터는 그냥 더블클릭으로 열려요.

---

## 4단계: 알림 받기 (선택)

AI 서비스에 문제가 생기면 맥에서 알림으로 알려주는 기능이 있어요.

1. 화면 오른쪽 위 **메뉴바에 생긴 작은 아이콘** 클릭
2. 팝업에서 **"환경설정..."** 클릭
3. **"상태 변경 시 알림"** 토글을 켜세요
4. 맥이 알림 권한을 물으면 **"허용"**

> 알림을 거부했다면: 시스템 설정 → 알림 → AIStatusMenubar에서 다시 켤 수 있어요.

---

## 5단계: 맥 켤 때 자동으로 실행하기 (선택)

매번 켜기 귀찮으면:

1. 메뉴바 아이콘 클릭 → **환경설정**
2. **"로그인 시 자동 시작"** 토글 켜기

---

## 사용법

설치하고 나면 화면 **오른쪽 위 메뉴바에 작은 색깔 아이콘**이 생깁니다. 이게 5개 AI 서비스 상태를 종합한 결과예요.

- **아이콘 클릭** → 서비스별 상세 상태 펼쳐 보기
- **각 서비스 클릭** → 그 회사 공식 상태 페이지를 사파리/크롬에서 열어줌
- **환경설정**에서 표시할 서비스, 알림, 확인 주기 등을 조정할 수 있어요

#### 1) 이 링크를 클릭하세요

👉 **https://github.com/cfcf26/ai-status-menubar/issues/new**

#### 2) GitHub 계정으로 로그인

- 계정이 없으면 무료로 가입할 수 있어요 (이메일만 있으면 1분)
- 이미 GitHub을 쓰시면 그냥 로그인

#### 3) 제목과 내용 적기

**제목 (Title)** — 무슨 일이 일어났는지 한 줄로:
- 예: "ChatGPT가 멈췄는데 아이콘이 계속 초록이에요"
- 예: "환경설정 창을 열면 글자가 잘려요"
- 예: "Grok 칸이 항상 회색이에요"

**내용 (본문)** — 아래 양식을 **복사해서 빈칸을 채워주세요**:

```
[무슨 일이 있었나요?]
한두 문장으로 설명해주세요.


[어떻게 하면 똑같이 일어나나요?]
1. 
2. 
3. 


[원래는 어떻게 되어야 하나요?]



[내 맥 정보]
- macOS 버전: (예: 15.7.4)
- 맥 종류: (예: MacBook Air M2)
- 앱 다운로드한 날짜: (예: 2026-05-17)
```

#### 4) 스크린샷 붙이면 더 좋아요

이상한 화면이 보이면:
1. **`Cmd + Shift + 4`** 누르고 원하는 영역 드래그하면 스크린샷이 저장됩니다
2. 저장된 이미지를 본문 입력란에 **드래그&드롭**하면 자동으로 첨부돼요

#### 5) 맨 아래 초록 버튼 **"Submit new issue"** 클릭

끝! 제보 감사합니다 🙏

## 자주 묻는 질문

**Q. 이 앱이 내 데이터를 가져가나요?**
A. 아니요. 각 AI 회사의 **공개 상태 페이지**(누구나 볼 수 있는 페이지)만 주기적으로 확인합니다. 로그인이나 API 키 같은 건 일절 쓰지 않아요.

**Q. 인터넷 사용량이 많이 늘어나나요?**
A. 거의 없어요. 1분에 한 번씩 작은 데이터(몇 KB)만 받습니다.

**Q. "손상되었습니다"라고 뜨면서 안 열려요.**
A. 드물게 그런 경우가 있어요. 터미널(`응용 프로그램 → 유틸리티 → 터미널`)을 열고 아래 명령을 복사해서 붙여넣고 엔터:
```
xattr -dr com.apple.quarantine /Applications/AIStatusMenubar.app
```

**Q. 메뉴바에 아이콘이 안 보여요.**
A. 메뉴바 공간이 부족해서 가려졌을 수 있어요. Bartender 같은 메뉴바 관리 앱을 쓰신다면 거기서 확인해주세요. 또는 다른 앱을 종료해서 공간을 확보해보세요.

**Q. 다 회색이에요.**
A. 인터넷 연결을 확인해보시고, 메뉴바 아이콘 → 새로고침 버튼을 눌러보세요. 회사 네트워크나 방화벽 때문일 수도 있어요.

**Q. 삭제하고 싶어요.**
A. `응용 프로그램` 폴더에서 AIStatusMenubar를 휴지통으로 옮기면 끝입니다.
